usage-bar: context and usage limits above the Claude Code prompt

A one-line bar that shows how much room you have left: tokens in the context window, and how much of your 5-hour and weekly limits you've used, with reset countdowns. Every section is optional.

What the bar shows

SectionWhat it shows
ctxTokens in the context window, used/total (84k/200k). Before the first response it shows –/200k. While you're viewing a subagent's transcript, it is labelled agent and shows that subagent's context instead.
5hHow much of your 5-hour limit you've used, and how long until it resets.
weekHow much of your weekly limit you've used, and how long until it resets.

Labels and track are dim. A section turns yellow from 70% and red from 90%; both thresholds can be changed. If the line doesn't fit a narrow terminal, the meters go first, then the countdowns.

Where the numbers come from

Everything comes from Claude Code itself. The mod doesn't poll or send any requests.

  • Context updates after every model request, so it moves with each tool call during a long turn, not only when the turn ends. Each subagent's context is tracked the same way.
  • Limits arrive with each response, and also mid-turn whenever a window moves by a whole point. They appear only on Pro and Max plans, after the first response of the session. With an API key, Bedrock or Vertex, only ctx is shown.
  • Reset countdowns are relative (42m, 2h14m, 3d4h), so they're right in any time zone, and they update every 30 seconds, also while you're idle.
  • Resets while idle: when a window's reset time passes with no new response, the 5-hour window drops to 0% with no countdown (a new window only starts with your next message) and the weekly window drops to 0% and counts down to the same time next week.
  • Other sessions: usage from Claude on other devices or sessions shows up with this session's next response.
  • After /clear or /resume: the bar stays. After /clear the context shows –/200k until the next response.

Configuration

Change these in /config, or under pluginConfigs in settings.json.

OptionDefaultWhat it does
show_contexttrueShow the context-window section.
show_five_hourtrueShow the 5-hour limit section.
show_weeklytrueShow the weekly limit section.
show_resettrueShow reset countdowns.
show_meterstrueShow the small meter beside each value.
placementabove-promptabove-prompt gives the bar its own line. footer appends a compact, dim version to the hint line under the input.
warn_pct70Percentage at which a section turns yellow.
critical_pct90Percentage at which a section turns red.

Example: show only the limits, without meters.

{
  "pluginConfigs": {
    "usage-bar@{{market}}": {
      "options": { "show_context": false, "show_meters": false }
    }
  }
}

To hide the bar for a moment, collapse the band with ctrl+x ctrl+a.

How it is built

usage-bar is a mod: a plugin of function hooks that draws into Claude Code's own interface, which is why it needs Claude Code 2.1.288 or later. It runs no scripts, makes no network calls and adds nothing to Claude's context. The hooks seed figures at session start, refresh context after each model request, redraw countdowns on a 30-second clock and render the band above the prompt. Formatting and fitting logic is pure and covered by tests.

FAQ

How do I see my Claude Code usage limits in the terminal?

Install usage-bar. It shows how much of the 5-hour and weekly limits you have used, with reset countdowns, in one line above the prompt. The numbers appear after the first response of a session on Pro and Max plans.

How do I see how full the Claude Code context window is?

usage-bar's ctx section shows tokens used out of the window size, for example 84k/200k, and updates after every model request, including for subagents.

Does usage-bar replace my status line?

No. It draws its own band above the prompt (or in the footer hint line), so your status line stays as it is.

Why don't the 5-hour and weekly sections show up?

They need a Pro or Max plan and appear after the first response of the session. With an API key, Bedrock or Vertex there are no plan limits, so only the context section is shown.
