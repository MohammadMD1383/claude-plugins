FAQ

How do I know how much of a long task Claude Code has finished?

Install progress-bar. Claude gets a tool for reporting how much of the task is done, and the percentage, what it is working on and the time elapsed show in a bar above the prompt.

Is the percentage accurate?

It is Claude's own estimate of the share of the whole task that is finished, and the plugin tells it to count the work still ahead (tests, verification) and to lower the number when it finds more work. It is far better than no signal, but it is an estimate. The bar also says when Claude has gone quiet or stopped before 100%.

Does it use the built-in todo list?

No. It is a separate tool that does one thing: set a percentage. That is easier for a model to keep up than a checklist, and it is easier for you to read at a glance.

Does it cost tokens?

A little: a short instruction in the system prompt and one small tool call at each milestone. Turn the instruction off with the auto_report option if you would rather ask for progress yourself.
