How to install Claude Code plugins from a marketplace

Claude Code plugins add commands, skills, hooks and interface mods to Claude Code. They are distributed through marketplaces: catalogs, usually a GitHub repository, that list one or more plugins. You add a marketplace once, then install any plugin from it.

Quick version

/plugin marketplace add MohammadMD1383/claude-plugins
/plugin install usage-guard@{{market}}

The general form is /plugin marketplace add <owner/repo>, then /plugin install <plugin>@<marketplace>, where <marketplace> is the name the marketplace registers under (here {{market}}), not the repository name.

Install inside a Claude Code session

  1. Add the marketplace. The source can be a GitHub owner/repo, any git URL, a local directory or a hosted marketplace.json. 
    /plugin marketplace add MohammadMD1383/claude-plugins

    On success Claude Code prints Successfully added marketplace: {{market}}. Add #ref to pin a branch or tag, for example owner/repo#v1.2.0.

  2. Install the plugin. 
    /plugin install usage-bar@{{market}}

    In a session this opens the plugin's details in the /plugin panel, so you can review what it adds and pick a scope before confirming.

  3. Or browse. Run /plugin with no arguments. The Discover tab lists plugins from all your marketplaces; type to search and press Enter to open one.
  4. Check it loaded. The Installed tab in /plugin lists the plugin with its scope. A plugin's commands appear namespaced, for example /usage-guard:status.

On Claude Code v2.1.275 or later you can add the marketplace and install in one step:

/plugin install usage-guard --marketplace MohammadMD1383/claude-plugins

Install from your shell

The same operations work as ordinary terminal commands, which is handy for setup scripts and dotfiles:

claude plugin marketplace add MohammadMD1383/claude-plugins
claude plugin install usage-guard@{{market}}
claude plugin install usage-bar@{{market}}
claude plugin list

Plugins installed from the shell load the next time you start Claude Code, or in an open session after you run /reload-plugins. In claude -p and other non-interactive runs, /plugin isn't available, but plugins you already installed do load.

Choose a scope

ScopeWho gets itWhere it's recorded
user (default)You, in every project.Your user settings.
projectEveryone working in this repository..claude/settings.json, which you commit.
localYou, in this repository only.Local, uncommitted project settings.
 
claude plugin install usage-guard@{{market}} --scope project

Committing a project-scoped plugin turns it on for collaborators but doesn't download it to their machines; each collaborator runs the install command once. When a plugin is set at several scopes, local overrides project, and project overrides user.

Configure a plugin

Plugins can declare options. You are prompted for the main ones when you enable the plugin, and can change them later in /config or from the plugin's Configure options item on the Installed tab. From the shell:

# show a plugin's options and which are unset
claude plugin configure usage-bar@{{market}}

# set options at install time
claude plugin install usage-bar@{{market}} --config show_meters=false

Update plugins

Auto-update is on by default only for Anthropic's official marketplaces. For community and third-party marketplaces such as this one it is off; turn it on in /plugin → Marketplaces → select the marketplace → Enable auto-update.

To update now:

claude plugin update usage-guard@{{market}}

Or open /plugin → Marketplaces, select the marketplace and choose Update marketplace to update every plugin you installed from it. Note that claude plugin marketplace update on its own only refreshes listings and leaves installed plugins at their current versions. A running session keeps the version it loaded until you run /reload-plugins or start a new session.

Disable or uninstall

claude plugin disable usage-bar@{{market}}
claude plugin enable usage-bar@{{market}}
claude plugin uninstall usage-bar@{{market}}            # add --keep-data to keep its data
claude plugin marketplace remove {{market}}             # also uninstalls its plugins

Inside a session, /plugin enable, /plugin disable and /plugin uninstall open the panel to make the same change.

Check what a plugin does first

A plugin can run hooks, scripts and MCP servers on your machine, so install only from sources you trust and read the details pane before confirming. Two habits help:

  • Read the plugin's README and source. Good plugins document what they run, read, write and send over the network, like the privacy sections of usage-guard.
  • Run claude plugin details <name> to see the plugin's components and its Always-on token cost: the tokens it adds to every session where it is enabled.

Troubleshooting

  • The install can't find the plugin: use the marketplace's registered name after @ ({{market}}), not the repository name. claude plugin marketplace list shows the names.
  • The plugin installed but does nothing: open the Errors tab in /plugin, and run /reload-plugins or restart Claude Code.
  • A mod doesn't appear: mods (plugins that draw into the interface, like usage-bar) need a recent Claude Code; usage-bar needs 2.1.288 or later. Check with claude --version.
  • Hooks fail on Windows: plugins that use scripts need their runtime. usage-guard needs Python 3 on PATH.
  • Plugins missing in the cloud: cloud sessions, including claude.ai/code in the browser, don't load the plugins installed on your own machine.

FAQ

What is a Claude Code plugin marketplace?

A marketplace is a catalog of plugins described by a .claude-plugin/marketplace.json file, usually in a git repository. You add it once with /plugin marketplace add, and its plugins then install with /plugin install plugin@marketplace.

Can I install a Claude Code plugin without opening a session?

Yes. Run claude plugin marketplace add and claude plugin install in your shell. The plugin loads the next time you start Claude Code.

How do I share a plugin with my team?

Install it with --scope project. That records it in .claude/settings.json, which you commit. Each collaborator then runs the same install command once.

Do plugins update automatically?

Only when auto-update is on for their marketplace. It is on by default for Anthropic's official marketplaces and off for third-party ones; turn it on from the Marketplaces tab in /plugin.
