Install

Run these inside Claude Code. You only add the marketplace once; after that, every plugin in it is one command away.

  1. Add the marketplace 
    /plugin marketplace add {{owner_repo}}
  2. Install any plugin 
    /plugin install <plugin>@{{market}}

    Or run /plugin and browse the Discover tab.

  3. Keep them up to date

    In /plugin → Marketplaces, select {{market}} and turn on auto-update, or update one plugin with claude plugin update <plugin>@{{market}}.

Installing from the shell, sharing plugins with a team, or configuring options? Read the full guide to installing Claude Code plugins.

What every plugin here aims for

Plugins run code on your machine and can cost tokens on every request, so these are the rules each one is built to.

  • One job, done wellSmall, focused plugins you can combine, instead of one plugin that does everything.
  • Cheap on contextNo always-on prompts or MCP servers unless a plugin truly needs them. Check any plugin with claude plugin details.
  • TransparentEach README says what the plugin runs, reads, writes and sends over the network. No telemetry.
  • TestedPlugins ship with test suites that run in CI on every push.
  • Fails safeA plugin error should never block or break your Claude Code session.
  • Free and openMIT licensed. Read the source, fork it, or open an issue on GitHub.

FAQ

What is a Claude Code plugin marketplace?

A marketplace is a catalog of Claude Code plugins, usually a GitHub repository with a .claude-plugin/marketplace.json file. You add it once with /plugin marketplace add, and every plugin it lists can then be installed with /plugin install plugin@marketplace.

How do I install a plugin from this marketplace?

In Claude Code, run /plugin marketplace add {{owner_repo}} once, then /plugin install followed by the plugin name and @{{market}}. You can also run the same commands from your shell as claude plugin marketplace add and claude plugin install.

Are these plugins free?

Yes. Every plugin in this marketplace is free and open source under the MIT license.

Are these official Anthropic plugins?

No. This is an independent community marketplace by MohammadMD1383 and is not affiliated with or endorsed by Anthropic. All source code is public on GitHub.

Will new plugins be added?

Yes. New plugins appear in the marketplace as they are released. Turn on auto-update for the marketplace in /plugin to get new versions automatically, and watch the GitHub repository to hear about new plugins.

How do I request a plugin or report a bug?

Open an issue on the GitHub repository. Bug reports, plugin ideas and pull requests are all welcome.
